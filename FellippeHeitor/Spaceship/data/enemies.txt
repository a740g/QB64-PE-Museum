; Spaceship enemy definitions
; One enemy per line:  ENEMY <NAME> key=value ...
;
;  sprite / sprite2   sprite names from sprites.txt (sprite2 = disguise for DRILLER)
;  title              boss name for the health bar (underscores become spaces)
;  hp, pts            hit points and score
;  color              0-15, RANDOM, SAUCER (random cycling) or a list like 9,9,3 (cycles)
;  move               PATTERN STRAIGHT SINE DIVE HOVER DRIFT ORBIT FOLLOW ATTACHED ANCHORED
;                     MIRROR ESCAPE BOSS EGG MINE LAYER DRILLER GATE LIGHTNING JELLY PHANTOM
;  speed              cells/second, or cells per step for PATTERN (a range like 1-2 is random)
;  vspeed, amp, period   vertical speed, sine amplitude (rows) and period (seconds)
;  pattern, patflip   PATTERN vertical steps; patflip=1 mirrors them for the top half
;  reverse, chase     PATTERN: bounce at edges / chase the ship (the original kamikazes)
;  spread             pool spawns appear up to this many cells past the right edge
;  fire               NONE BEAM AIMED SPREAD3 RING8 ZAP SPORE BURST
;  firerate, bspeed   seconds between shots, bullet speed
;  wounded            enemy it turns into when hit but not killed
;  ondeath            SPLIT:<ENEMY>:<count> or SHRAPNEL
;  drop               <PICKUP>:<percent>  (LIFE ENERGY SHIELD FREEZE WEAPON BOMB MISSILE OVERDRIVE)
;  boss               1 boss body, 2 boss part, 3 vital part     ai  boss behavior
;  invuln, ghost      cannot be damaged / bullets pass through
;  knock              cells pushed back per hit (the original used 5)
;  touch              1 = hurts the ship on contact (default)
;  framerate          seconds per animation frame

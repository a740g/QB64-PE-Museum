; Spaceship sprite library
;
; SPRITE <name> <width> <height>
; MAP <char> <cp437 code>   remap one character for this sprite
; FRAME                     followed by <height> rows between | fences
; COLORS                    optional, after a frame: one hex color per cell, - = entity color
; END
;
; Default legend (so the file stays plain ASCII):
;   #  219 full block     ^  223 upper half     _  220 lower half
;   [  221 left half      ]  222 right half
;   .  176 light shade    :  177 medium shade   %  178 dark shade
;   (space) transparent   anything else prints as itself
;
; The first sprites below were converted from the original 2016 game data.
